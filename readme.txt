Tested up to: 6.4
Requires PHP: 7.2

A small plugin to create buy-X-get-Y rules per product. Uses Select2/AJAX for product selection in admin.

Installation:

1. Upload the `woocommerce-bogo-builder` folder to `/wp-content/plugins/`.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Edit a product and open the 'BOGO Rules' tab to start adding rules.
