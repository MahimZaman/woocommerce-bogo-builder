# WooCommerce BOGO Builder

Creates buy-X-get-Y promotions on individual WooCommerce products.

## Installation

1. Place this directory at `wp-content/plugins/woocommerce-bogo-builder/`.
2. Activate WooCommerce, then activate **WooCommerce BOGO Builder**.

## Usage

Edit a product and open the **BOGO Rules** tab. Choose the qualifying quantity and reward product, save the rule and check the offer in the cart.
